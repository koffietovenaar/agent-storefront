# Sample-pack validation

This directory is an intentionally generic template, not a completed client
project. Its placeholders are visible so it cannot be mistaken for finished
repository documentation.

Checks performed on 2026-07-28:

- Every relative Markdown link resolves inside this directory.
- The two issue forms are valid YAML.
- Each issue form has a unique identifier for every input.
- The pull-request checklist makes no claim that tests were run.
- No credentials, client names, testimonials, or revenue claims are present.
- Security reporting is explicitly directed away from public issues.

The paid documentation service adapts this structure to one real repository and
runs the repository's documented commands where they are safely runnable.
